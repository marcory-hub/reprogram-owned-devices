# Analyze: what is the argument?

Extract and structure reasoning from text.

## Building blocks

| Term | Role |
| :--- | :--- |
| Statement | Declarative sentence that can be true or false |
| Argument | Premises offered as reason to accept a conclusion |
| Premise | Statement supporting another statement |
| Conclusion | Statement the argument tries to establish |
| Intermediate conclusion | Supported by lower premises and used to support a higher conclusion |
| Subargument | Argument supporting one of the premises of the main argument |
| Assumption | Proposition taken as true without adequate proof in the text |

**Argument vs heated exchange:** logic concerns reasons for thinking a claim is true, not quarrelling.

**Argument vs explanation:** if premises try to show *that* the conclusion is true, it is an argument; if they try to show *why* it is true while the conclusion is already accepted, it is an explanation. "Because" can mark either.

**Premise objection:** targets truth of a premise. **Inference objection:** targets whether premises support the conclusion (hidden bridge may be the real target).

## Standard form

Number premises and conclusion. Use paraphrase when it clarifies the logic (faithful, declarative, one claim per line). Multiple accurate reconstructions are possible; prefer the strongest charitable reading.

**Identify arguments:** ask whether someone is trying to establish a statement as true by basing it on another statement.

## Structure indicators (hints only)

**Premise:** since, because, for, as, given that, for the reason that, is shown by the fact that...

**Conclusion:** therefore, so, thus, hence, consequently, implies that, it follows that...

Indicators are not failsafe. Use the **substitution test:** swap in another indicator from the same list; if the sentence breaks, it was probably not functioning as that indicator.

## Complex structure

**Main conclusion:** depends on other statements but does not support any higher statement in the passage.

**Top-down:** find main conclusion, then premises and subarguments.

**Bottom-up:** extract candidate statements, then fit structure. Authors omit steps; not every sentence belongs.

**Joint support:** multiple premises must all be true together; removing one breaks the inference (often `(from 1-2)`).

**Independent support:** separate premise groups each could justify the conclusion alone (often `(from 1-2, 3 independently)`).

**Negative test:** negate a proposed hidden premise; if the argument still works, it was not required.

## Main conclusion (6 guidelines)

1. Title (may be editorial).
2. Conclusion indicators.
3. Placement: often start or end of section or paragraph.
4. Controversy test: conclusion often more controversial than premises.
5. Context: author, goals, genre.
6. Dependency: main conclusion is not used to support another claim.

## Charity and linking

**Principle of charity:** reconstruct so the argument is as strong as possible (valid for deductive patterns, inductively strong for inductive ones). Prefer specific, defensible bridges over sweeping generalizations. Weaken universal claims to "most" when that is more plausible (**guarding**).

**Term linking:** important terms in the conclusion should appear in premises; important terms in premises should appear in the conclusion or another premise.

## Hidden premises (required output)

Always try to surface unstated premises.

**Procedure:**

1. Reconstruct in standard form; note where the inference fails the validity test.
2. List topics in each premise and in the conclusion; add bridge claims for unlinked topics.
3. Supply missing premises to make the argument valid or inductively strong (charity).
4. Flag normative conclusions from descriptive premises (**is-ought gap**); add explicit normative bridge.
5. Flag absolutes and causal leaps as likely hidden premises.
6. State each hidden premise as an explicit declarative claim.
7. Label: **acknowledged**, **explicit-unacknowledged**, or **unstated**.
8. Apply negative test; do not invent premises the argument does not need.

## Rhetorical shortcuts (not arguments)

| Move | What it does |
| :--- | :--- |
| **Assuring** | Signals there are further reasons without giving them (citing authority, "everyone knows", "studies show") |
| **Guarding** | Weakens a claim ("most", "probably", "it is possible that") to make it harder to refute |
| **Discounting** | Acknowledges an objection then dismisses it ("A but B", "although... nevertheless") |

Treat these as flags to probe for real premises, not as substitutes for argument.

## Intellectual virtues (reconstruction)

Charity, curiosity, intellectual honesty, humility. Note alternative reconstructions when plausible.
