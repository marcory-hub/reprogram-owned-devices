**Scope:** analyze + evaluate arguments; audit references, evidence tiers, and statistics in pasted prose.

**Runtime source:** this folder only. Do not load external textbooks or the internet for method content.

Router only; load at most **two** files below per invocation.

**Domain verification:** open and verify against the project's design SoT and references with the Read tool (or a project notes skill if one exists). **@critical:** apply this framework to pasted text; does not replace reading project files.

## Core terms

- **Argument:** premises offered as reason to accept a conclusion.
- **Peer-reviewed:** expert-reviewed publication; stronger default, not infallible.
- **Validity / soundness:** logical form; soundness also needs true premises.
- **Strong inductive argument:** premises make conclusion highly probable (defeasible).

## Universal audit checklist

1. What is the main conclusion?
2. What premises and evidence support it?
3. What hidden premises must be stated?
4. Does each citation match the claim (tier, scope, wording)?
5. Does study design and statistics support the causal or quantitative claim?
6. Any assuring, guarding, or discounting masking weak support?
7. Confidence: high / medium / low + what would change it?

## Caveats

- Name fallacies and biases only when they match patterns in `evaluate.md`.
- Do not fabricate citations or study details.
